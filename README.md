# 🎀 AI Voice Studio

可愛い女の子の声を自由に生成できるAI音声生成Webツール

## 📋 プロジェクト概要

このツールは、2つのモードでAI音声を生成できます：
1. **プロンプトモード** - テキストで声のイメージを記述して音声生成
2. **ボイスクローンモード** - サンプル音声から声を複製して音声生成

## ✨ 実装済み機能

### 🎨 プロンプトモード
- ✅ 声のイメージをテキストプロンプトで入力
- ✅ 5種類の感情・トーン選択（通常・元気・囁き・感動・泣き声）
- ✅ 台詞入力欄
- ✅ ElevenLabs v3-TTS APIによる音声生成
- ✅ 生成音声の再生プレイヤー
- ✅ MP3ダウンロード機能

### 🎤 ボイスクローンモード
- ✅ 音声ファイル（MP3/WAV）のドラッグ&ドロップアップロード
- ✅ アップロードファイルのプレビュー再生
- ✅ ElevenLabs Voice Clone APIによる声の解析・複製
- ✅ 台詞入力欄
- ✅ クローン音声でのTTS生成
- ✅ 生成音声の再生プレイヤー
- ✅ MP3ダウンロード機能

### 🎵 共通機能

## 🚀 使い方

### 1. APIキーの取得
GenSpark AI APIキーを取得してください：
- [GenSpark AI](https://api.genspark.ai/) でアカウント作成
- APIキーを取得

### 2. ツールの起動
- `index.html` をブラウザで開く
- 右上のAPIキー入力欄にAPIキーを入力

### 3. プロンプトモードでの音声生成
1. 「✨ プロンプトで作る」タブを選択
2. 「声のイメージ」欄に声の特徴を記述
   - 例：「明るく元気な10代の女の子。高めのトーン、語尾が跳ねる話し方、アニメキャラクターのような可愛らしさ」
3. 感情・トーンを選択（😊 通常、⚡ 元気、🌙 囁き、💕 感動、😢 泣き声）
4. 「台詞」欄に読み上げるテキストを入力
5. 「🎵 音声を生成する」ボタンをクリック
6. 生成完了後、再生またはダウンロード

### 4. ボイスクローンモードでの音声生成
1. 「🎤 声をクローンする」タブを選択
2. 音声ファイル（MP3/WAV）をドラッグ&ドロップ
   - ⚠️ 動画ファイルは現バージョンでは未対応
3. アップロードしたファイルをプレビュー再生で確認
4. 「台詞」欄に読み上げるテキストを入力
5. 「🎤 クローン音声を生成する」ボタンをクリック
6. 生成完了後、再生またはダウンロード

## 📡 API仕様

### プロンプトモード API

**Endpoint:** `POST https://api.genspark.ai/v1/audio/speech`

**Headers:**
```json
{
  "Content-Type": "application/json",
  "Authorization": "Bearer YOUR_API_KEY"
}
```

**Request Body:**
```json
{
  "model": "elevenlabs/v3-tts",
  "input": "読み上げるテキスト",
  "voice": {
    "type": "voice_description",
    "voice_description": "声のイメージプロンプト + 感情タグ"
  }
}
```

**Response:** `audio/mpeg` バイナリ

### ボイスクローンモード API（2ステップ）

#### ステップ1: ボイスクローン作成

**Endpoint:** `POST https://api.genspark.ai/v1/audio/speech`

**Request Body:**
```json
{
  "model": "elevenlabs/voice-clone",
  "voice_files": ["data:audio/mpeg;base64,..."]
}
```

**Response:**
```json
{
  "voice_id": "cloned_voice_id_string"
}
```

#### ステップ2: クローン音声でTTS生成

**Endpoint:** `POST https://api.genspark.ai/v1/audio/speech`

**Request Body:**
```json
{
  "model": "elevenlabs/v3-tts",
  "input": "読み上げるテキスト",
  "voice": {
    "type": "custom_voice_id",
    "voice_id": "ステップ1で取得したvoice_id"
  }
}
```

**Response:** `audio/mpeg` バイナリ

## ⚠️ 制限事項・未実装機能

### 現在の制限
- ❌ **動画ファイルからの音声抽出**: 未対応
  - 動画（MP4等）から音声を抽出する機能は、ブラウザ単体では困難
  - 実装にはFFmpeg.wasmなどの大規模ライブラリが必要
  - 現状は音声ファイル（MP3/WAV）のみ対応

- ⚠️ **履歴の永続化**: 制限あり
  - LocalStorageに保存されるのはメタデータのみ
  - 音声データ（Blob URL）は再読み込み後は利用不可
  - 完全な履歴再生には音声ファイルのサーバー保存が必要

- ⚠️ **ファイルサイズ制限**: 25MB
  - APIの制限に基づく
  - 大きな音声ファイルはアップロード不可

## 🛠️ トラブルシューティング

### APIキーエラー
- APIキーが正しく入力されているか確認
- APIキーの権限を確認（Audio API使用可能か）

### 音声が生成されない
- インターネット接続を確認
- ブラウザのコンソールでエラーメッセージを確認
- APIの利用制限（レート制限、クォータ）を確認

### ファイルがアップロードできない
- ファイルサイズが25MB以下か確認
- ファイル形式がMP3/WAVか確認
- ブラウザの対応状況を確認（最新版推奨）
